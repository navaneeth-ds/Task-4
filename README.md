# 📊 Financial Sales Dashboard

## 📌 Task Overview

This project is part of the **Data Analyst Internship – Task 4**.

The objective of this task is to design an interactive dashboard using **Power BI** to analyze financial sales data and present useful business insights.

## 🎯 Objectives

- Analyze total sales performance.
- Analyze total profit.
- Analyze sales price.
- Understand sales trends over time.
- Compare sales performance across customer segments.
- Create an interactive dashboard using slicers and filters.

## 🛠️ Tools Used

- 📊 Power BI Desktop
- 📄 CSV Dataset
- 📑 Microsoft PowerPoint

## 🗃️ Dataset

The project uses a financial sales dataset containing information related to:

- Sales
- Profit
- Sales Price
- Product
- Segment
- Country
- Date
- Year

## 📈 Dashboard Components

The Power BI dashboard contains:

- 💰 Total Sales
- 📈 Total Profit
- 💵 Sum of Sales Price
- 📊 Sales Trend Over Time
- 👥 Sales by Segment
- 🎛️ Year Slicer
- 🎛️ Segment Slicer

The slicers allow users to interact with the dashboard and analyze the data based on selected years and customer segments.

## 💡 Key Insights

- Total Sales provides an overview of the overall sales performance.
- Total Profit helps evaluate the profitability of the business.
- Sales Trend Over Time shows how sales change over the selected period.
- Sales by Segment helps compare performance across different customer segments.
- Year and Segment slicers allow interactive filtering of the dashboard.
